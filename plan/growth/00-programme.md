# Growth · the programme

How the 13 weeks run, rebuilt with the habit science in the books below: a cue for every block, a two-minute start for every kind of task, a coach's note for every week, and an identity for every chapter. The format is in Part 1, section 23 of the plan.

## Anchors

The default cue for each block, as an implementation intention and a habit stack. Edit yours on the Growth tab; Today shows the one for the block you are in.

| Block | When | Cue |
| --- | --- | --- |
| morning | Weekday morning, before work | After I pour my morning tea, I sit at the desk, open Today and press Start. Phone stays in the other room. |
| night | Weekday night | After dinner and the dishes, I open Today, read my why line, and press Start on the night task. |
| saturday | Saturday | After breakfast on Saturday, I open the learning loop and start the cold attempt before I look at anything else. |

## Two-minute starts

When a task feels too big, do only this. It counts as starting. Often it becomes the whole task.

| Type | Start |
| --- | --- |
| `dsa` | Open the problem and write the brute force as a comment. Nothing else. |
| `boss` | Read the problem twice and draw one small example by hand. |
| `concept` | Write the why-question at the top of a blank note and one sentence of your own answer. |
| `infra` | Open a terminal and run one command from the task (`docker ps`, `kubectl get pods`). |
| `design` | Write the functional requirements as three bullets. |
| `design2` | Read the two options and pick one. Write why in one line. |
| `lld` | Write the names of the main classes, nothing more. |
| `maths` | Write what you are deriving and the first line of the setup. |
| `capstone` | Open the repo and write today's milestone as a TODO at the top of one file. |
| `redraw` | Draw the first three boxes from memory. |
| `read` | Read the first section and write one line about it. |
| `mock` | Open the mock page and read the prompt aloud. |
| `story` | Write the S of the STAR story in two lines. |
| `career` | Open the doc or the site and write the first line. |
| `mindset` | Write one honest sentence. |
| `review` | Fill in this week's points from Progress. |
| `ai` | Write the prompt you would give and what a good answer must contain. |
| `paper` | Read the abstract and write the one number to find. |

## Coach notes

One line on the Monday card, for the week ahead.

| Wk | Note |
| --- | --- |
| 1 | **Start small, on purpose.** This week is about showing up at the same time every day, not about how much you do. Two minutes counts. |
| 2 | **One cue, every day.** Use the same anchor every morning. Diwali Sunday is light: one problem, or nothing. Never miss twice. |
| 3 | **Retrieval beats rereading.** Close the tab and explain the concept from memory before you check. The struggle is the learning. |
| 4 | **Track, don't judge.** Look at your calendar in Settings: count the days you showed up, not the points you missed. |
| 5 | **The plateau starts here.** Designs get harder and progress can look flat. That is the plateau of latent potential: the work is stored, not lost. Keep the system. |
| 6 | **Play your own game.** Payments is your home turf. Go one level deeper than the plan asks; this is where your stories come from. |
| 7 | **Mix it up.** The DSA weeks are mixed now: interleaving feels harder and works better. Expect about 30% misses; that is the Goldilocks zone. |
| 8 | **Someone is waiting.** Your first mock this week. A partner is an accountability contract: you show up because they do. Nerves mean your body is getting ready. |
| 9 | **Boredom is the test.** The novelty is gone. Professionals keep the schedule when it stops being exciting. Fall in love with boredom. |
| 10 | **Reputation now.** First applications go out. How you show up in every call counts: say less, listen more, follow up in writing. |
| 11 | **Stories are practised, not written.** Say each STAR story out loud three times this week. The first version is always too long. |
| 12 | **Concentrate your forces.** Pick the target list and stop spreading thin. Ten good applications beat fifty generic ones. |
| 13 | **Know your number.** Negotiation is a skill you practise before the call: anchor, label, ask calibrated questions. Then apply. |

## Why did it fail

When a habit stops, it is the system, not you. Ask one question per law, and fix the first one that answers yes.

| Law | Ask yourself | Fix |
| --- | --- | --- |
| Make it obvious | Did I forget, or was there no clear cue at a clear time? | Write an implementation intention, stack it on a habit you never skip, and put the cue in sight. |
| Make it attractive | Did it feel like a chore I *had* to do? | Bundle it with something you like, reframe it as "get to", and do it with people for whom it is normal. |
| Make it easy | Was the first step too big, or was there friction before it? | Cut it to the two-minute version and prime the setup the night before. |
| Make it satisfying | Did nothing good happen right after it? | Tick it at once, track it, and add a small immediate reward that fits who you want to be. |
